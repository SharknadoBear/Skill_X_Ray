# Skill X-Ray

Skill X-Ray casts an agent skill into validated JSON and a standalone interactive HTML workflow graph. The graph helps inspect documented states, gates, tools, examples, iterations, and explicit subskill calls. In graph version 0.2, an **Example** button explains one illustrative input at each working state, gate, and inter-skill call. The source skill remains authoritative.

Start with [SKILL.md](SKILL.md) for the workflow and its boundaries. The repository also contains the schema and notation in `schemas/` and `references/`, the Python inventory, validation, and rendering scripts in `scripts/`, the standalone viewer assets in `assets/` and `templates/`, and example graphs in `examples/`.

## Check the repository

```powershell
python -m unittest discover -s tests -v
```

This repository is the version-controlled maintenance copy of the installed `skill-xray` skill. Project objective and session memos are kept in the sibling `Memo` folder of the local working directory.

## Package a graph for paper supplementary material

The generated `<skill>-xray.html` is self-contained **for viewing the graph**. It embeds the graph JSON, styling, viewer code, vendor libraries, and icon; it opens offline without the Skill X-Ray installation or network access. It does not contain the target skill's complete source instructions. A link from an inter-skill call to another X-Ray page also needs that separate page if readers should follow it.

For a publication package, include these files:

| File | What it provides |
| --- | --- |
| `<skill>-xray.html` | The interactive, offline figure readers open. This is the only file required to view one graph. |
| `<skill>-xray.json` | The canonical, machine-readable graph, including evidence references and the illustrative case. It allows independent validation or a new render. |
| `validation-report.json` | The validation result, warnings, graph counts, and semantic fingerprint at the time of casting. |
| `casting-summary.md` | A short explanation of the cast, assumptions, ambiguous or omitted relationships, and whether the target skill was executed. |
| `source-inventory.json` | The target skill's file inventory, including hashes and flags for explicitly referenced files. It does not contain the files themselves. |
| `source-skill/` | A snapshot of the target `SKILL.md` and, at minimum, every cited reference or script needed to read the original instructions. This is source material, not generated by X-Ray. |

Record the target skill version or source hashes and the Skill X-Ray Git commit in a small package manifest. Include linked X-Ray HTML pages alongside the main page when inter-skill navigation is part of the supplement. The HTML and JSON describe the documented structure; the source snapshot remains the full record of the skill instructions.
